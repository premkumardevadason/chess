# Chess Piece SVG Asset Manifest

This directory contains SVG images for classic Staunton chess pieces, to be used in the board rendering UI.

## Naming Convention
- wK.svg — White King
- wQ.svg — White Queen
- wR.svg — White Rook
- wB.svg — White Bishop
- wN.svg — White Knight
- wP.svg — White Pawn
- bK.svg — Black King
- bQ.svg — Black Queen
- bR.svg — Black Rook
- bB.svg — Black Bishop
- bN.svg — Black Knight
- bP.svg — Black Pawn

## Source
- Public domain SVGs from Wikimedia Commons (Staunton style)
- Example: https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces

## Usage
- These files are loaded at runtime and rendered in the chess board UI instead of text initials.
